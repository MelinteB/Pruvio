# Multi-picture Campaign Studio candidate
Up to five merchant-owned JPEG/PNG/WebP uploads, 6MB per input, 12MB combined normalized source data. First selected image is primary; thumbnails can be removed or promoted. AI receives all photos in order. PNG combines them into a primary-plus-supporting collage; GIF/MP4 export the same collage (multi-image animation is not yet implemented, single-photo animation unchanged). The existing promotion stores one finished asset: source selection is session-only and must be reuploaded when reopening a saved draft. No database migration or changes to publication/loyalty rules. Requires real R2, provider, device and preview testing. Business standalone repository not updated.
