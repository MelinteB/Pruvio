# Day 1 Setup - Pruvio

## Goal

Prepare the local development environment and project structure for Pruvio.

## Pruvio Concept

Pruvio is a WhatsApp-first modular assistant.

Users send receipts, invoices, screenshots, QR codes, PDFs or text through WhatsApp.

Pruvio detects the intent and activates the right service module.

## Core First

The first build will focus on Pruvio Core:

- WhatsApp input/output
- User management
- Case management
- Document storage
- Module router
- Admin dashboard

## Future Modules

- Split Bill
- Refund Claim
- Warranty Claim
- Subscription Cancellation
- Payment Reminder
- Document Reminder
